## NSFW Check Env

Server-side NSFW detection supports these environment variables:

- `NSFW_CHECK_URL`: NSFW detection API endpoint
- `NSFW_CHECK_TOKEN`: optional bearer token for the NSFW API
- `NSFW_CHECK_TIMEOUT`: request timeout in milliseconds, default `10000`
- `NSFW_CHECK_PORN_THRESHOLD`: block threshold for the `porn` score, default `0.03`
