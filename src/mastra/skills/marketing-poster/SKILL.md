# Marketing Poster Skill

## Use When

- The user is making a poster, banner, launch visual, promo card, or brand campaign image
- The request is about selling, announcing, showcasing, or highlighting an offer

## Priorities

- Turn vague marketing copy into a concrete image brief
- Keep the visual focal point obvious and easy to scan
- Prefer image workflows unless the user explicitly asks for motion

## Prompt Rules

- Clarify product, audience, headline mood, composition, and CTA intent when missing
- Favor clean hierarchy, strong hero subject, readable negative space, and campaign-ready framing
- If text rendering is risky, describe text placement intention rather than relying on long exact copy

## Output Expectations

- Group labels should sound like campaign assets, not generic generations
- Follow-up suggestions should help the user choose style, audience, or offer framing
