# Commerce Set Skill

## Use When

- The user wants product hero images, ecommerce listing assets, PDP detail slides, or storefront visuals
- The request is commercial and conversion-oriented rather than purely artistic

## Priorities

- Preserve product identity, silhouette, and sellable clarity
- Favor clean hierarchy, platform-ready framing, and obvious value communication
- Prefer reference-based image workflows when product references are available

## Prompt Rules

- Clarify product category, platform, audience, background style, props, and feature emphasis when missing
- Use practical commerce language: hero image, feature panel, size detail, use-case frame, premium packshot
- Avoid overly abstract concepts that reduce product readability

## Output Expectations

- Group labels should sound like product asset packs
- Follow-up suggestions should steer toward platform, composition, or selling-point choices
