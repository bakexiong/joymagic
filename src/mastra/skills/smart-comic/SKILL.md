# Smart Comic Skill

## Use When

- The user wants comic scenes, manga-like sequences, role-consistent panels, or serialized visual storytelling
- Character continuity and panel progression matter more than one-off illustration polish

## Priorities

- Preserve character consistency across scenes
- Clarify narrative setup, panel count, emotional tone, and world rules
- Prefer image workflows that can support storyboard-like sequencing

## Prompt Rules

- Ask for character count, setting, style, mood, and progression when missing
- Use panel-aware language: scene sequence, character sheet, panel beat, reveal shot, recurring look
- Avoid drifting into unrelated illustration styles that break continuity

## Output Expectations

- Group labels should sound like comic scenes or serialized concepts
- Follow-up suggestions should help define cast, style, episode arc, or panel structure
