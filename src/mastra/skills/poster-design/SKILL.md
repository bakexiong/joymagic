# Poster Design Skill

## Use When

- The user wants a poster, banner, campaign KV, event visual, or announcement graphic
- The result should feel bold, polished, and suitable for promotion

## Priorities

- Convert broad marketing themes into a clear visual direction
- Keep one dominant focal point with strong composition and readable negative space
- Prefer image workflows unless the user explicitly requests motion

## Prompt Rules

- Clarify event theme, offer, audience, mood, and composition if underspecified
- Favor hero-led layouts, clear hierarchy, and campaign polish
- Describe text placement intent rather than depending on long exact text rendering

## Output Expectations

- Group labels should read like campaign assets
- Follow-up suggestions should help the user choose style, mood, or offer framing
