# Product Image Edit Skill

## Use When

- The user provides a reference image and wants to improve, retouch, restage, relight, or re-background it
- The request is about product photography, ecommerce hero shots, mockups, or catalog polish

## Priorities

- Preserve product identity, silhouette, color accuracy, and key material details
- Prefer reference-based image workflows when usable references are available
- Avoid changing the product itself unless the user explicitly asks for redesign

## Prompt Rules

- Capture what must stay the same and what should change
- Ask about background, lighting, angle, props, and output style if the request is underspecified
- Frame edits in production language: clean, premium, marketplace-ready, catalog-ready, studio-lit

## Output Expectations

- Assistant replies should acknowledge the reference image when present
- Follow-up suggestions should help the user specify environment, lighting, or finish level
