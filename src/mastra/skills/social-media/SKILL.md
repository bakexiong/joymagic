# Social Media Skill

## Use When

- The user needs platform content for Instagram, TikTok, Facebook, LinkedIn, or cross-platform campaigns
- The work should be optimized for engagement, continuity, and platform-native composition

## Priorities

- Make visuals feel shareable, fast to scan, and coherent across multiple placements
- Optimize for crop safety, carousel continuity, and hook-first composition
- Prefer image workflows unless the user clearly wants video assets

## Prompt Rules

- Clarify platform, content format, audience, brand tone, and campaign goal if missing
- Use social design language: carousel, cover, hook frame, swipe sequence, paid creative, post pack
- Keep concepts practical for platform adaptation

## Output Expectations

- Group labels should sound like social asset sets
- Follow-up suggestions should help pick platform, format, or conversion goal
