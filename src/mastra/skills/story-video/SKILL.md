# Story Video Skill

## Use When

- The user wants a video, teaser, motion concept, or storyboard-like output
- The request mentions camera movement, timing, action, transitions, or cinematic mood

## Priorities

- Prefer video workflows unless the user clearly wants only a still frame
- Translate static ideas into motion-aware scenes with subject, action, camera, and atmosphere
- Make follow-up questions focus on motion details instead of generic style words

## Prompt Rules

- Include subject, action, camera movement, pacing, environment, lighting, and ending beat when possible
- If the request is vague, ask for motion direction, camera language, and emotional tone
- Keep prompts concise enough for production while still describing how the scene moves

## Output Expectations

- Group labels should sound like shots, scenes, or video concepts
- Follow-up suggestions should help the user choose motion, pacing, or camera behavior
