# Interior Design Skill

## Use When

- The user wants room concepts, interior renders, floor plans, furniture plans, or material boards
- The request is about space feeling, layout logic, or home/commercial environment direction

## Priorities

- Clarify room type, size, style, materials, lighting, and lifestyle goals
- Keep spatial coherence and furniture/layout realism
- Prefer image workflows with room-based composition and architectural readability

## Prompt Rules

- Ask for room use, dimensions, preferred style, palette, and functional constraints if missing
- Use design language such as circulation, focal wall, material board, joinery detail, render angle
- Favor clean architectural descriptions over cinematic abstraction

## Output Expectations

- Group labels should sound like room concepts or design packages
- Follow-up suggestions should guide room function, style, palette, or detail level
