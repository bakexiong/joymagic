## 新增需求

### 需求：图片 AI 全场景页面必须支持移动端表单优先布局

系统必须为图片 AI 的所有场景页与模型页提供仅在移动端生效的表单优先页面编排，并保持桌面端现有页面结构不变。

#### 场景：用户在移动端访问图片 AI 页面

- **当** 用户在移动端访问图片 AI 相关页面
- **那么** 页面首屏优先展示该页面对应的核心生成表单区域
- **并且** 表单区域位于页面主要 SEO 文案之前

#### 场景：用户在桌面端访问图片 AI 页面

- **当** 用户在桌面端访问同一路由
- **那么** 系统继续展示当前桌面端页面结构
- **并且** 本次移动端改造不得改变桌面端模块顺序

### 需求：图片 AI 移动端页面必须提供统一的场景切换与模型切换

系统必须在所有图片 AI 移动端页面的表单区域上方提供统一切换能力，并且切换范围与 header 的 `图片AI` 菜单一致。

#### 场景：用户查看移动端页面顶部切换区

- **当** 用户在移动端访问任一图片 AI 场景页或模型页
- **那么** 页面在表单区域上方展示场景切换下拉框
- **并且** 当前场景若存在模型列表，则同时展示模型切换下拉框

#### 场景：用户切换到其他场景

- **当** 用户在场景切换下拉框中选择其他场景
- **那么** 系统跳转到该场景对应的目标路由
- **并且** 若该场景包含模型列表，则使用其默认模型页面或通用场景页作为目标

#### 场景：用户切换到其他模型

- **当** 用户在模型切换下拉框中选择其他模型
- **那么** 系统跳转到该模型对应的目标路由

### 需求：移动端图片 AI 页面必须将原 SEO 模块后移

系统必须在移动端图片 AI 页面中保留原有 SEO 模块内容，但将其移动到表单区域之后展示。

#### 场景：移动端页面渲染原有内容模块

- **当** 系统渲染图片 AI 页面原有的 hero、features、faq、cta 等内容
- **那么** 在移动端中这些模块位于表单区域之后
- **并且** 文案字段值和内容本身保持不变

#### 场景：桌面端页面渲染原有内容模块

- **当** 系统在桌面端渲染同一路由
- **那么** 原有内容模块顺序保持不变

### 需求：移动端图片 AI 页面必须与当前路由保持选择器同步

系统必须保证场景切换器、模型切换器和当前路由之间保持一致，避免切换器状态与当前页面不匹配。

#### 场景：用户进入某个模型页

- **当** 用户直接进入某个图片 AI 模型页
- **那么** 场景切换器显示该模型所属场景
- **并且** 模型切换器显示当前模型

#### 场景：用户进入无模型列表的场景页

- **当** 用户直接进入 `image-eraser`、`image-background-remover`、`image-upscaler` 或 `qwen-image-layered` 等无模型列表场景页
- **那么** 场景切换器显示当前场景
- **并且** 页面不展示模型切换器
