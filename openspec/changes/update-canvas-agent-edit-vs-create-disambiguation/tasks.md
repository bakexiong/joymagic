## 2. Agent 协议

- [ ] 2.1 在 supervisor agent 输出结构中新增“编辑目标决策”字段
- [ ] 2.2 将当前 `executionMode` 作为一等输入传给 supervisor agent
- [ ] 2.3 在已有节点且用户意图不明确时，先返回澄清结果而不是直接落图

## 3. Workflow 与画布执行

- [ ] 3.1 让 workflow 能根据“原节点新增 / 新建节点”决策走不同执行路径
- [ ] 3.2 原节点新增路径在原节点上下文中新建一个派生节点，不覆盖原节点
- [ ] 3.3 新建路径创建新的节点组，并在组内新增文本节点和对应 workflow 节点
- [ ] 3.4 `auto` 模式在节点创建完成后立即触发 `/generate`
- [ ] 3.5 `ask` 模式在节点创建完成后仅创建待确认节点，不立即触发 `/generate`

## 4. 前端交互

- [ ] 4.1 在 agent UI 中展示“在原节点上新增 / 新建节点”的澄清选项
- [ ] 4.2 将用户选择回传给服务端，避免下一轮再次歧义
- [ ] 4.3 `ask` 模式在节点创建后弹出场景参数卡，并由用户确认后再调用 `/generate`
