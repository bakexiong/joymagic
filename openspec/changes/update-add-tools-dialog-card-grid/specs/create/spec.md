## 修改需求
### 需求：工具添加弹窗（AddToolsDialog）展示模式
系统必须将 `AddToolsDialog` 的工具选择展示从列表模式调整为卡片网格模式，并支持固定（Pin）交互。

#### 场景：用户浏览工具并通过缩略图识别
- **当** 用户打开 `AddToolsDialog`
- **那么** 系统以卡片网格展示工具，每张卡片包含缩略图与标题
- **并且** 缩略图使用 `tool.icon_url`（若存在），否则使用默认占位展示

#### 场景：用户固定或取消固定工具
- **当** 用户点击某工具卡片的 Pin 按钮
- **那么** 系统调用现有固定逻辑（`onToggleTool(toolUrl)`）切换固定状态
- **并且** UI 立即反映固定状态（Pin 高亮/选中样式）

#### 场景：用户切换分类筛选
- **当** 用户切换到 Image 或 Video 分类
- **那么** 系统只展示该分类下的工具卡片

#### 场景：资源地址统一走 CDN
- **当** 系统渲染卡片缩略图
- **那么** 图片 URL 必须经过 CDN 重写（`toCdnUrl()`），保证域名统一
