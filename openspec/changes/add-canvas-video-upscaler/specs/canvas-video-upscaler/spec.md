# canvas-video-upscaler 规范

## 新增需求

### 需求：画布视频节点高清增强入口

系统必须在 `/create/canvas` 的视频节点中提供“高清增强”入口，并在真正提交任务前弹出确认面板。

#### 场景：用户打开高清增强弹窗

- **当** 用户点击视频节点工具栏中的“高清增强”
- **那么** 系统必须弹出确认面板
- **并且** 面板中必须允许选择目标分辨率

### 需求：高清增强按钮显示积分

系统必须在高清增强确认面板的生成按钮旁显示当前参数下的积分估算。

#### 场景：目标分辨率变化时刷新积分

- **当** 用户在高清增强面板中切换目标分辨率
- **那么** 系统必须重新估算对应积分
- **并且** 更新生成按钮旁的积分显示

### 需求：统一场景请求参数

系统必须继续通过统一的 `/api/ai/[scene]/generate` 路径发起视频高清增强任务，不得在前端直连 provider API。

#### 场景：提交视频增强任务

- **当** 用户在视频节点中确认发起高清增强
- **那么** 系统必须请求 `/api/ai/canvas-video-upscaler/generate`
- **并且** 请求体至少包含 `video`、`target_resolution`、`duration`

### 需求：异步任务回流结果节点

系统必须在视频增强任务提交后创建结果占位节点，并在任务完成后回填生成结果。

#### 场景：增强任务成功完成

- **当** `/api/ai/canvas-video-upscaler/generate` 返回异步任务 ID
- **那么** 系统必须创建一个视频结果占位节点
- **并且** 在状态接口返回完成后，将增强后的视频 URL 回填到该结果节点
