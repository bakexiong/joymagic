## 新增需求

### 需求：`/tools/image-effect` 必须支持 Mango Photo Effects 特效目录

系统必须将来源于 `https://mangoanimate.com/zh-tw/ai/photo-effects` 的目标照片特效样式接入当前 `/tools/image-effect` 页面，使其能够作为模板库中的可选特效被展示和切换。

#### 场景：用户浏览图片特效模板库

- **当** 用户访问 `/tools/image-effect`
- **那么** 模板库中必须展示新增的 Mango 风格照片特效样式
- **并且** 每个新增特效必须具备可识别的标题、slug 和预览图

#### 场景：用户切换新增特效

- **当** 用户在模板库中点击新增特效的 `Try Template`
- **那么** 工作区必须切换到对应特效
- **并且** 当前预览、默认选中状态和底部介绍区必须同步更新

### 需求：新增 Mango 特效必须具备可展示的示例图资产

系统必须为新增的 Mango 特效提供示例图资产，以支持模板库卡片、工作区预览和底部内容区展示；这些示例图可以使用 `gpt-image-2` 生成。

#### 场景：用户查看新增特效预览

- **当** 用户在模板库或工作区查看某个新增特效
- **那么** 系统必须展示与该特效风格匹配的示例图
- **并且** 示例图不得缺失或回退为无关占位内容

#### 场景：维护者补充新增特效

- **当** 维护者为 Mango 特效目录补充新样式
- **那么** 系统必须允许通过现有数据结构挂接标题、描述、预览图和示例图
- **并且** 不得要求为每个特效单独发明新的页面渲染逻辑
