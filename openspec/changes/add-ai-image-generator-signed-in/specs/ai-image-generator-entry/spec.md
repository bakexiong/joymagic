## 新增需求

### 需求：AI Image Generator 页面必须为已登录用户提供无路由跳转的入口组件

系统必须在 `/ai-image-generator` 页面为已登录用户展示与未登录态 UI 完全一致的入口组件，区别在于已登录用户切换场景和模型时不进行路由跳转，所有操作在当前页面内完成。

#### 场景：已登录用户访问入口页

- **当** 已登录用户访问 `/ai-image-generator`
- **那么** 系统展示已登录态入口组件（`AiImageGeneratorSignedIn`）
- **并且** 不再展示旧版 `ImageGenerator` 组件或临时占位符
- **并且** 未登录用户继续展示既有的 `AiImageGeneratorGuest` 组件

#### 场景：已登录态组件的视觉布局与未登录态一致

- **当** 系统渲染已登录态入口组件
- **那么** 页面布局（标题区、控制卡片、场景下拉框、模型下拉框、表单工作区）与未登录态入口组件完全一致
- **并且** 样式常量（深色工作台基调、表面色、输入框样式）与未登录态共享同一套定义
- **并且** 移动端和桌面端的响应式布局与未登录态保持一致

### 需求：已登录态入口组件切换场景时必须不进行路由跳转

系统必须保证已登录用户在切换场景时仅更新页面内状态，不触发路由导航，页面始终停留在 `/ai-image-generator`。

#### 场景：已登录用户切换到带模型列表的场景

- **当** 已登录用户在场景下拉框中选择一个包含模型列表的场景（如 `文本生成图片`、`图片转图片`）
- **那么** 系统更新模型下拉框的选项列表
- **并且** 自动选中该场景下的第一个模型
- **并且** 表单工作区加载对应模型的表单组件
- **但是** 浏览器 URL 保持为 `/ai-image-generator` 不变

#### 场景：已登录用户切换到无模型列表的场景

- **当** 已登录用户在场景下拉框中选择一个无模型列表的场景（如 `图片擦除`、`背景移除`、`图片放大`）
- **那么** 系统隐藏模型下拉框
- **并且** 表单工作区加载该场景对应的表单组件
- **但是** 浏览器 URL 保持为 `/ai-image-generator` 不变

### 需求：已登录态入口组件切换模型时必须不进行路由跳转

系统必须保证已登录用户在切换模型时仅更新页面内表单组件，不触发路由导航。

#### 场景：已登录用户在同一场景下切换模型

- **当** 已登录用户在模型下拉框中选择不同的模型
- **那么** 表单工作区平滑切换到对应模型的表单组件
- **并且** 浏览器 URL 保持为 `/ai-image-generator` 不变

#### 场景：表单组件动态加载

- **当** 已登录用户切换场景或模型导致需要加载新的表单组件
- **那么** 表单工作区显示加载状态
- **并且** 加载完成后渲染新的表单组件
- **并且** 不影响场景和模型下拉框的交互响应

## 修改需求

### 需求：未登录态与已登录态入口组件必须共享公共模块

系统必须将两个入口组件的共享代码提取为独立公共模块，避免代码重复和样式漂移。

> 修改自已有的 `AI Image Generator 页面必须支持独立的未登录态入口组件` 需求，增加公共模块提取的约束。

#### 场景：共享样式常量

- **当** 系统渲染已登录态或未登录态入口组件
- **那么** 两个组件引用同一份样式常量定义（`WORKBENCH_*_CLASS`）
- **并且** 修改样式常量时两个组件同步生效

#### 场景：共享表单组件映射

- **当** 系统需要根据目标 URL 加载表单组件
- **那么** 两个组件引用同一份 `FORM_COMPONENTS` 映射表
- **并且** 新增或删除表单组件时只需修改一处

#### 场景：共享场景提取逻辑

- **当** 系统需要从 navItems 提取场景和模型结构
- **那么** 两个组件引用同一份 `extractImageAiScenes` 和 `findFirstSceneWithWorkspace` 函数
- **并且** 共享 `SceneNode`、`ModelNode` 等类型定义

#### 场景：未登录态行为保持不变

- **当** 未登录用户在入口页切换场景或模型
- **那么** 系统继续沿用未登录态原有的路由跳转行为
- **并且** 本次已登录态接入不得改变未登录态的页面跳转策略
