## 新增需求

### 需求：首页模型案例展示区必须由后台配置驱动

系统必须提供可由后台维护的首页模型案例配置，用于在移动端首页展示多个模型分组及其案例内容。

#### 场景：管理员配置模型案例内容

- **当** 管理员进入后台首页配置入口
- **那么** 管理员可以维护多个模型分组
- **并且** 每个分组至少可以配置标题、查看全部链接、排序和启用状态
- **并且** 每个分组下可以维护多个案例项

#### 场景：管理员配置单个案例项

- **当** 管理员编辑某个模型分组的案例项
- **那么** 系统允许配置案例封面、标题、作者名、目标链接、排序和启用状态
- **并且** 支持维护多个案例项以适配“会有很多的模型展示”的场景

### 需求：移动端首页必须按后台配置顺序展示模型案例

系统必须根据后台配置结果，在移动端首页的双 CTA 区域之后展示模型案例区。

#### 场景：前台读取有效配置

- **当** 后台存在有效的首页模型案例配置
- **那么** 移动端首页按配置中的模型顺序展示模型案例
- **并且** 每个分组内的案例项按配置顺序展示
- **并且** 被停用的分组或案例项不出现在前台

#### 场景：按模型展示瀑布流案例

- **当** 系统渲染某个模型的案例展示区
- **那么** 该模型必须作为独立模块展示
- **并且** 模块内的案例项以瀑布流或错落布局展示
- **并且** 不再使用仅按 `Image Models` 或 `Video Models` 的聚合展示模式

#### 场景：用户点击查看全部或案例项

- **当** 用户点击模型分组的“查看全部”入口
- **那么** 系统跳转到该分组配置的目标页面
- **当** 用户点击某个案例项
- **那么** 系统跳转到该案例项配置的目标页面

### 需求：首页模型案例配置必须具备安全降级能力并保证首页可用

系统在读取首页模型案例配置失败、为空或格式无效时，必须保证首页其他内容继续展示，并且不得阻断首页可用性。

#### 场景：后台尚未配置首页模型案例

- **当** 前台读取不到任何有效模型案例配置
- **那么** 系统跳过模型案例展示区
- **并且** 继续渲染后续 SEO 模块和 footer

#### 场景：后台配置格式异常

- **当** 首页模型案例配置存在缺字段、排序无效或格式损坏
- **那么** 系统忽略无效分组或无效案例项
- **并且** 不导致首页整体渲染失败
