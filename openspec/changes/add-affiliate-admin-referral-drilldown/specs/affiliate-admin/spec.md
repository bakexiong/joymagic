## 修改需求

### 需求：Admin 必须提供内嵌式分销管理模块

系统必须在现有 `admin` 管理后台中提供分销管理模块，并包含数据概览、推广者管理、申请审核、佣金管理、提现管理、全局配置页面。

#### 场景：有权限的管理员访问分销模块

- **当** 用户已拥有 `admin.access` 与 `admin.affiliate.read` 权限
- **那么** 系统必须允许其访问 `/admin/affiliate/*` 页面
- **并且** 页面必须复用现有 admin 布局与导航体系

#### 场景：管理员进入默认分销入口

- **当** 用户访问 `/admin/affiliate`
- **那么** 系统必须跳转到默认概览页
- **并且** 默认概览页必须展示分销关键运营指标

#### 场景：管理员查看单个推广者的归因明细

- **当** 管理员在推广者列表中选择某个推广码查看明细
- **那么** 系统必须展示该推广者对应的注册用户列表
- **并且** 系统必须展示该推广者对应的订单转化用户列表
- **并且** 转化列表必须包含被推广用户身份与对应订单或续订的转化信息
