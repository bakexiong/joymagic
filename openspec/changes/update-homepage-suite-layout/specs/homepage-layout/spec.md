## 新增需求

### 需求：首页采用工作台式桌面布局

系统必须将首页桌面端呈现为工作台式布局，而不是传统横向导航营销首页。

#### 场景：桌面端访问首页

- **当** 用户在桌面端访问首页
- **那么** 页面应展示顶部营销位、品牌与用户操作 Header、左侧主导航 Sidebar，以及以创作输入框为中心的主工作区

### 需求：Header 不再承载主导航

系统必须将首页 Header 的职责收敛为品牌信息与用户操作区，不再承担横向一级导航。

#### 场景：用户查看首页 Header

- **当** 用户浏览首页顶部 Header
- **那么** 应看到 Logo/品牌信息以及充值入口、多语言切换、用户积分、头像等用户操作
- **并且** 不应在 Header 中看到首页主导航菜单

### 需求：Sidebar 承接首页主导航

系统必须将首页主导航入口集中到左侧 Sidebar 中。

#### 场景：用户浏览首页导航

- **当** 用户查看首页左侧 Sidebar
- **那么** 应能看到按任务或能力分组的导航入口
- **并且** Sidebar 应可承接原先 Header 中的首页主导航职责

### 需求：首页输入框成为首屏主要入口

系统必须将首页输入框设计为首屏最核心的创作入口。

#### 场景：用户进入首页首屏

- **当** 用户首次进入首页
- **那么** 应首先感知到中心化的创作输入区
- **并且** 输入区应整合场景、模型、参数和生成按钮，形成可直接开始的工作流

### 需求：首页中部内容区遵循工具发现优先顺序

系统必须将首页中部内容组织为工具发现、能力说明、案例展示和升级引导的顺序。

#### 场景：用户向下浏览首页

- **当** 用户滚动浏览首页首屏以下内容
- **那么** 应优先看到工具发现与能力入口
- **并且** 之后依次看到案例、优势、FAQ 和升级相关内容
