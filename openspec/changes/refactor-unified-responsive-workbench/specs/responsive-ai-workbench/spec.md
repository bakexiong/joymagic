## 新增需求

### 需求：统一响应式 AI 工作台

系统必须提供一套同时覆盖移动端和桌面端的响应式 AI 工作台，统一 AI 场景页的工作台基座。

#### 场景：首页移动端保持现状

- **当** 用户在移动端访问首页
- **那么** 系统必须继续保留现有首页移动端编排
- **并且** 系统不得因为工作台基座统一而强制替换 `mobile-homepage`

#### 场景：图片或视频 AI 页面在移动端访问

- **当** 用户在移动端访问 `text-to-image`、`image-to-image`、`text-to-video` 或 `image-to-video` 相关页面
- **那么** 系统必须使用统一响应式工作台承载场景切换、模型切换和生成表单
- **并且** 系统不得继续依赖单独的移动端专用工作台组件作为主入口

#### 场景：桌面端访问不退化

- **当** 用户在桌面端访问首页或 AI 场景页
- **那么** 系统必须继续提供完整工作台能力
- **并且** 统一后的响应式工作台不得导致已有桌面端生成功能缺失

#### 场景：统一配置来源

- **当** 不同端渲染同一 AI 场景
- **那么** 系统必须复用同一套 `desktop-playground` schema / config 定义
- **并且** 禁止为移动端额外维护一套独立参数结构
