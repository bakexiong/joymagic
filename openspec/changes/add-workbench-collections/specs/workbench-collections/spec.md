## 新增需求

### 需求：工作台 Collections 必须支持真实列表与管理

系统必须让登录用户在工作台 `Collections` 视图中查看并管理自己的合集。

#### 场景：查看合集列表

- **当** 登录用户打开工作台 `Collections` 标签页
- **那么** 系统必须返回该用户当前的合集列表

#### 场景：创建合集

- **当** 登录用户输入合法名称并创建合集
- **那么** 系统必须持久化该合集
- **并且** 新合集必须立即显示在列表中

#### 场景：重命名合集

- **当** 登录用户修改现有合集名称
- **那么** 系统必须更新对应合集名称
- **并且** 列表必须刷新为最新名称

#### 场景：删除合集

- **当** 登录用户删除某个合集
- **那么** 系统必须移除该合集
- **并且** 列表中不再显示它

### 需求：合集名称必须校验

系统必须校验合集名称，避免创建无效或重复的合集。

#### 场景：名称为空

- **当** 登录用户提交空白合集名称
- **那么** 系统必须拒绝本次创建或重命名请求

#### 场景：名称重复

- **当** 登录用户创建或重命名为自己已有的合集名称
- **那么** 系统必须拒绝本次请求并返回明确错误
