## 注意事项

1. **通用性优先**：所有实现都应该是通用的，不要硬编码 PixVerse 特定的逻辑
2. **参数组合 key 的一致性**：确保前端和后端生成的参数组合 key 格式一致（按字母顺序排序）
3. **UI 自适应**：UI 应该根据参数定义和布局配置自动生成，不要为每个场景写专门的 UI
4. **不支持组合的处理**：在多处进行验证（配置、UI、计算逻辑）
5. **向后兼容**：不影响现有其他场景的配置和计算逻辑
6. **性能考虑**：参数组合查找应该高效，考虑使用 Map 或缓存
7. **可扩展性**：设计时考虑未来可能的扩展需求（如参数依赖关系、动态范围等）
