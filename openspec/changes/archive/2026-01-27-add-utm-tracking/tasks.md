   - 创建独立的 utm_tracking 表用于历史追踪
   - 添加相关索引优化查询性能
   - 生成数据库迁移脚本：`0006_add_utm_tracking.sql`

2. **客户端 UTM 捕获**
   - 实现 URL 参数解析和 Cookie 存储
   - 创建全局 UTM 追踪组件
   - 同时保存到 Cookie（用于订单关联）和数据库（用于历史追踪）
   - 创建 API 端点：`POST /api/utm/track`

3. **订单 UTM 关联**
   - 服务端从 Cookie 读取 UTM 数据
   - 创建订单时自动关联 UTM 参数

4. **UTM 统计和查询**
   - 创建统计查询 API：`GET /api/admin/utm/stats`
   - 创建订单导出 API：`GET /api/admin/orders/export`
   - 支持按 campaign、source、medium、时间范围筛选
   - 实现权限检查（仅管理员可访问）

### 设计方案
采用**混合方案**：
- **utm_tracking 表**：记录所有 UTM 访问历史，支持多次访问追踪
- **order 表 UTM 字段**：冗余存储，方便快速查询订单的 UTM 来源
- **优点**：兼顾历史追踪和查询性能
- **缺点**：数据冗余，但可接受
