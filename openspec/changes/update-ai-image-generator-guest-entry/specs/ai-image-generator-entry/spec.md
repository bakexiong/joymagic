## 新增需求

### 需求：AI Image Generator 页面必须支持独立的未登录态入口组件

系统必须将 `/ai-image-generator` 页面设计为登录态分支容器，并将未登录用户界面封装为独立组件，以便后续增加已登录态组件时可按登录状态切换。

#### 场景：未登录用户访问入口页

- **当** 未登录用户访问 `/ai-image-generator`
- **那么** 系统展示新的未登录态入口组件
- **并且** 该组件不复用当前通用 `ImageGenerator` 页面设计

#### 场景：后续接入已登录态组件

- **当** 后续需要为已登录用户增加独立页面体验
- **那么** 系统可以在不改写未登录态组件主体的前提下新增并列的已登录态组件
- **并且** 页面容器按登录状态切换渲染

### 需求：未登录态入口页必须满足统一的页面布局与视觉约束

系统必须使未登录态入口页采用移动端优先的创作工作台布局，并保持高级、克制、可读的视觉表现。

#### 场景：用户进入未登录态入口页

- **当** 未登录用户进入 `/ai-image-generator`
- **那么** 页面按顺序展示标题区、控制卡片、动态表单工作区和辅助提示区
- **并且** 控制卡片作为首要视觉焦点展示场景选择与模型选择

#### 场景：页面应用视觉风格

- **当** 系统渲染未登录态入口页
- **那么** 页面采用深色工作台基调
- **并且** 使用金色作为 CTA、选中态或重点强调色
- **并且** 卡片允许使用轻量玻璃感样式
- **但是** 不得使用影响可读性的重模糊、低对比度或廉价霓虹效果

#### 场景：用户在移动端访问页面

- **当** 用户在移动端视口访问未登录态入口页
- **那么** 页面在 `375px` 宽度下保持完整可用
- **并且** 表单区域和选择器不因切换场景或模型产生明显布局跳变

### 需求：未登录态入口页必须复用图片 AI 菜单中的场景与模型结构

系统必须使未登录态入口页的场景与模型选择结构对齐 header 中 `图片AI` 菜单的可见范围，不得在入口页维护另一套不一致的导航层级。

#### 场景：用户查看场景下拉框

- **当** 未登录用户进入 `/ai-image-generator`
- **那么** 页面展示第一个场景下拉框
- **并且** 该下拉框包含 header `图片AI` 菜单中的一级可达场景
- **并且** 至少覆盖 `文本生成图片`、`图片转图片`、`图片擦除`、`背景移除`、`图片放大`、`Qwen 图片分层`

#### 场景：用户选择带模型列表的场景

- **当** 用户选择的场景在 header 菜单中包含模型级 `children`
- **那么** 页面展示第二个模型下拉框
- **并且** 模型列表、排序、文案和目标链接与该场景在 header 菜单中的配置保持一致

#### 场景：用户选择无模型列表的场景

- **当** 用户选择的场景在 header 菜单中直接配置了目标链接且没有模型级 `children`
- **那么** 页面不展示第二个模型下拉框
- **并且** 系统直接跳转到该场景对应页面

### 需求：未登录态入口页必须根据当前选择展示对应表单

系统必须使未登录态入口页下方表单内容跟随当前场景或模型选择变化，并与目标页面的核心生成表单能力保持一致。

#### 场景：用户切换到文生图模型

- **当** 用户在场景下拉框中选择 `文本生成图片` 且选定某个模型
- **那么** 页面下方展示与该模型目标页面一致的核心文生图表单
- **并且** 在用户确认后跳转到该模型页面

#### 场景：用户切换到图生图模型

- **当** 用户在场景下拉框中选择 `图片转图片` 且选定某个模型
- **那么** 页面下方展示与该模型目标页面一致的核心图生图表单
- **并且** 在用户确认后跳转到该模型页面

#### 场景：场景配置无效

- **当** 某个场景缺少可用目标链接或模型列表为空
- **那么** 系统不得渲染不可用的选择项
- **并且** 页面继续保持其他场景可用

### 需求：移动端首页 Create Image 入口必须导向新的未登录态入口页

系统必须保证移动端首页的 `Create Image` 入口在未登录用户路径上进入新的 `/ai-image-generator` 页面。

#### 场景：未登录用户点击移动端首页 Create Image

- **当** 未登录用户在移动端首页点击 `Create Image`
- **那么** 系统跳转到 `/ai-image-generator`
- **并且** 到达后展示新的未登录态入口组件
