## 新增需求

### 需求：工作台媒体面板支持日期范围筛选
桌面工作台的媒体面板必须支持用户通过筛选面板选择日期范围，并基于该范围过滤 `Creations` 与 `Uploads` 视图中的媒体项。

#### 场景：打开日期筛选器
- **当** 用户在 `Creations` 或 `Uploads` 视图点击筛选按钮
- **那么** 系统必须显示包含日期范围控件的筛选面板
- **并且** 用户必须能够浏览月份并选择起止日期

#### 场景：应用日期范围筛选
- **当** 用户选择了开始日期和结束日期并点击 `Apply`
- **那么** 系统必须仅显示日期落在该范围内的媒体项
- **并且** 已应用的日期范围在筛选面板重新打开时必须被保留

#### 场景：清空日期范围筛选
- **当** 用户点击 `Clear`
- **那么** 系统必须移除已选择和已应用的日期范围
- **并且** 媒体列表必须恢复为未按日期过滤的状态

#### 场景：取消未应用的选择
- **当** 用户修改了日期选择但点击 `Cancel` 或直接关闭面板
- **那么** 系统必须保留上一次已应用的日期范围
- **并且** 不得用未应用的临时选择更新媒体列表
