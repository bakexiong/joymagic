## 新增需求
### 需求：支持可选 Style 选择项
系统必须允许 `/tools` 下的通用生成表单根据工具配置展示一个可选的 `style` 选择项，交互方式与现有 effect 场景中的风格选择保持一致。

#### 场景：工具配置声明了 style 选项
- **当** 某个 text-to-image 或 image-to-image 工具在表单 schema 中声明了 `style` 字段及其可选项
- **那么** 表单应展示一个可选的风格选择控件
- **并且** 用户切换风格后，表单值应更新为对应的 style

#### 场景：模板预填包含 style
- **当** 用户从模板库进入工具页，且模板参数中包含 `style`
- **那么** 表单应以该 style 作为默认选中值

#### 场景：style 关联 ref 图
- **当** 用户选择的 style 选项包含对应的 `ref` 图
- **那么** 表单应将该 `ref` 图回填到上传附件区域
- **并且** 用户应能像查看普通上传参考图一样预览该 `ref` 图

#### 场景：style 关联 prompt
- **当** 用户选择的 style 选项包含对应的 `prompt`
- **那么** 表单应将该 `prompt` 回填到提示词输入区域
- **并且** 用户无需手动复制粘贴即可继续生成

#### 场景：工具未提供 style 数据
- **当** 某个工具未在表单 schema 中声明 `style` 字段，或没有可用的 style 选项
- **那么** 表单不应展示 style 控件
- **并且** 现有生成流程与参数提交行为保持不变

#### 场景：style 为可选项
- **当** style 字段被声明为非必填
- **那么** 用户可以在不选择 style 的情况下继续生成
- **并且** 提交参数时不应因为缺少 style 而阻塞
