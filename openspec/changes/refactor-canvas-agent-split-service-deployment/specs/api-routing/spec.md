## 修改需求

### 需求：内部 Agent 路由转发

系统必须允许主站 API route 将 Canvas Agent 请求转发到独立的内部 Agent 服务。

#### 场景：同步请求转发

- **当** 主站处理 Canvas Agent 普通消息请求
- **那么** 主站必须能够把规范化后的请求体转发给内部 Agent 服务
- **并且** 把 Agent 服务结果转换回主站当前响应结构

#### 场景：流式请求透传

- **当** 主站处理 Canvas Agent 流式消息请求
- **那么** 主站必须能够透传内部 Agent 服务的流式响应
- **并且** 不得要求前端改用新的公网 Agent 地址
